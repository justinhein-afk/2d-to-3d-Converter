# Statistics in Motion — chalk edition

This is the same 10s hyper-kinetic piece as `../statistics-bw`, with the same camera, timing and 120 BPM track. It's recoloured with a palette sampled from the reference photo, on a chalk-white background. The top-left and top-right indicators have been removed.

| Token | Hex | Source in photo |
|-------|-----|-----------------|
| BG | `#F4F1EA` | chalk white |
| INK | `#2A1A15` | espresso, from the hair |
| WALNUT | `#8B5A3C` | bookcase wood, used for both full-screen match cuts |
| TEAL | `#0F5257` | binders |
| SAGE | `#7F9566` | green book spines |
| BLUE | `#55627D` | blue book spines |
| TERRA | `#B8664A` | warm skin and red spines, used as the accent for arrows and highlights |
| SAND | `#C1B19C` | sofa, used for grid and texture |

The build steps are the same as in `../statistics-bw/README.md`, and `audio.js` is shared.
